            Learn from AI sessions

            Your coding sessions with Claude Code and Codex become notes: what you asked, how it ended, the files changed and the commands run. Secrets are taken out first, and Dream gathers sessions about the same work into one note. Transcripts are read on this computer only.

            Connect your coding agents

            Let Claude Code or Codex search this notebook before they dig into something, and save what they find as fresh memories. They talk to FastMind over MCP, on this computer.

            For Claude Code, one command sets it all up: /fastmind in any session writes up the work and saves it, and every session is written up on its own when it ends. agent uninstall takes it all away.

            Model

            FastMind's AI writes up each capture, answers your questions from your notes, and decides overnight what to merge, gather, archive and settle.

            Each capture is saved as you typed it at once, then written up a few seconds later: title, summary, key points, tasks, related notes and where it belongs. A note you've edited is never rewritten, the original is always kept, and History undoes it.

            Skills

            How the AI judges and writes, one skill per job. They decide the quality of your notes. Edit one to change it for this notebook; FastMind always adds today's date, your preferences, and the rule that notes are never instructions.
