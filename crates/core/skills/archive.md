# Decide what to archive

Each note below hasn't been used for a while and nothing links to it; `picked_because` says
which rule picked it. Archiving moves a note out of the notebook's folders into the archive,
where it stays searchable (ranked lower) and can be restored in one click. Archiving the right
notes keeps search sharp; archiving the wrong one hides something the user needed. Weigh each
note on its own.

## Archive it when its value has run out

- finished and done with: a completed checklist, a shipped task, a booked trip that's over;
- outdated or superseded: an old plan replaced by a later decision, instructions for a tool
  that's gone, a price or schedule that no longer holds;
- trivial or throwaway: a test note, a stray line, an empty template, a reminder whose moment
  has passed;
- a session or meeting note with no decision, finding or task worth keeping.

## Keep it when it still has value, however old

- reference that's still true: how something works, a recipe, a procedure, a contact;
- a decision and its reasons ("We chose Postgres over Mongo because…"): these matter most
  exactly when nobody remembers them;
- a lesson, a dead end, a post-mortem;
- anything personal: memories, people, health, family, writing, ideas the user cared about;
- anything you can't judge from the note. When in doubt, keep it.

## The reason

One plain sentence the user will read, specific to the note: "A finished packing list for a
trip in March." or "Records why the team chose Postgres; still the reason it's used." Not "It's
old."
